## Plain summary

When M10a is done, the app's big moments move:
- **Quest cleared:** the speed lines burst and the title slams in. Then the XP stamp thuds down in a splash of ink, and
  the stats panel slams in. Last, the XP bar fills from where it was while its number counts up.
- **Level-ups:** a bigger thud and splash.
- **Achievements:** a thud; the speed lines stay still.
- **The reveal:** the speed lines burst once and the class panel slams in.
- **The Shadow:** its painting creeps closer, its box slams in, and its stamp thuds.
- **The vow:** "Sworn" thuds.
- **Today:** it moves only when a sync changes something while you look: the bar fills, or the streak's flame thuds.
- **Reduced motion:** with "Remove animations" on, everything fades or doesn't appear.

A developer-only **Motion bench** replays every piece and moment on the emulator.

## Decisions this plan makes

The spec's decisions stand. These are the details the spec left open, settled here. Deviations from the spec are
marked.

1. **Every timing runs even when the phone asks for reduced motion** (`reduceMotion: ReduceMotion.Never` in `timing()`
   and `THUD_SPRING`).
   - **Why:** Reanimated's default (`ReduceMotion.System`) jumps an animation to its end when the phone's setting is
     on. The pieces choose their own reduced path (a fade), so that fade must actually run. Today `SlamIn`'s fade jumps;
     this fixes it.
   - **The setting:** Reanimated reads it once, at launch, from Android's `transition_animation_scale`
     (`NativeProxy.getIsReducedMotion`). So the checklist restarts the app after changing it.
2. **`FadeIn` is a fifth piece** (deviation: the spec's table has four new ones).
   - **Why:** the level-up portrait "rises 12 px and fades in", and an achievement's description "fades in". Neither is
     a slam or a thud.
   - **How:** it fades over 300 ms; `rise` also lifts it 12 px. With reduced motion, the fade alone over 180 ms.
3. **The ink is vermilion, seal and chalk** (deviation: the spec says "ink, vermilion and chalk"). Ink (#151515) can't
   be seen on the night or the void, where every burst sits.
4. **Today's "last value" lives inside the moving `XpBar`** (deviation in form, not behaviour, from decision 7's "small
   `usePrevious`-style hook in Today").
   - **How:** the bar keeps what it last showed in a ref. Any bar given a `level` fills from there on a change, so
     Today only passes `level`.
   - **The streak:** it uses `useGrowth`, which counts rises after the first value. Opening a screen never animates.
5. **The count-up runs through Reanimated, not a JavaScript timer.**
   - **How:** a shared value runs the count on the UI thread, and a `useAnimatedReaction` sends each whole number to
     React state (`scheduleOnRN`).
   - **Why:** Reanimated's Jest mock never calls reactions, so no test gets a state update outside `act`. In a test, a
     counting number stays at its start.
   - **Its accessibility label is always the final line.**
6. **Each celebration plays afresh.** The modal's content is keyed by the celebration (`level-7`, `achievement-<id>`),
   so the next one in the queue remounts and replays instead of reusing the finished views.
7. **The motion bench is its own developer screen** (`app/dev/motion.tsx` → `src/dev/routes/motion.tsx`), linked from
   the developer screen (deviation: the spec put a Motion section in the kit).
   - **Why:** Quest cleared is a full-screen scroll view and can't sit inside the kit's.
   - **The reduced-motion switch:** it applies to the pieces only. The moments follow the phone's own setting, which is
     the real path.
   - **The level-up and the achievement:** the bench queues them in the real store (a new `useGameStore()` in
     `store.ts`), so they show in the real modal.
8. **The version:** 0.3.0, versionCode 3 (spec decision 10). `MIN_APP_VERSION` stays 0.1.0.

```ts
// M10a: the motion rule's numbers (visual spec §3; spec 2026-10-14-m10a-motion-design.md) and the pure parts of the
// motion pieces. Every timing runs even when the phone asks for reduced motion (`ReduceMotion.Never`, plan decision 1):
// each piece picks its own reduced path (a fade), so Reanimated must not skip that fade to its end.
import { Easing, ReduceMotion } from 'react-native-reanimated';

export const SLAM_MS = 180;
export const SLAM_PX = 16;
export const FADE_MS = 180;
export const THUD_FROM = 1.3;
export const THUD_FADE_MS = 80;
/** Settles in about 270 ms, overshooting once to about 0.97. */
export const THUD_SPRING = { damping: 18, mass: 0.6, stiffness: 400, reduceMotion: ReduceMotion.Never } as const;
export const THUD_SETTLE_MS = 300;
export const RISE_MS = 300;
export const RISE_PX = 12;
export const BURST_MS = 400;
export const BURST_FROM = 0.6;
export const INK_MS = 600;
export const FILL_MS = 700;
export const WRAP_FILL_MS = 450;
export const FLASH_MS = 120;
export const REFILL_MS = 400;
export const CREEP_MS = 4_000;
export const CREEP_TO = 1.06;

/** A timing config that always runs (plan decision 1); ease-out unless told otherwise. */
export function timing(duration: number, easing = Easing.out(Easing.cubic)) {
  return { duration, easing, reduceMotion: ReduceMotion.Never };
}

/** When each part of a moment starts, in ms from the screen opening (spec decision 4). */
export const MOMENTS = {
  cleared: { stamp: 220, panel: 380, rank: 500, bar: 600 },
  level: { label: 100, number: 200, portrait: 450, line: 600 },
  achievement: { name: 100, rest: 350 },
  reveal: { panel: 150 },
  shadow: { stamp: 300 },
} as const;

/** The filled share of a bar, between 0 and 1. */
export function fillFraction(value: number, max: number): number {
  if (!(max > 0)) return 0;
  return Math.max(0, Math.min(1, value / max));
}

/** A level and the XP into it, as a bar shows them. */
export type BarPoint = { level: number; value: number; max: number };
export type Segment = { from: number; to: number };

/**
 * How a bar moves from what it showed to what it shows now (spec decision 5): up within a level is one fill; up across
 * a level fills to the end, then from empty (once, however many levels); anything else, a drop included, shows at once.
 */
export function fillSegments(was: BarPoint, now: BarPoint): Segment[] {
  const a = fillFraction(was.value, was.max);
  const b = fillFraction(now.value, now.max);
  if (now.level === was.level) return b > a ? [{ from: a, to: b }] : [];
  if (now.level > was.level) return [{ from: a, to: 1 }, { from: 0, to: b }];
  return [];
}

export type CountPlan = { from: number; delay: number; duration: number };

/** The level line's count, in step with the bar that starts after `delay`: across a level it counts only the last part. */
export function countPlan(was: BarPoint | null, now: BarPoint, delay: number): CountPlan | null {
  if (was === null) return null;
  const steps = fillSegments(was, now);
  if (steps.length === 1) return { from: was.value, delay, duration: FILL_MS };
  if (steps.length === 2) return { from: 0, delay: delay + WRAP_FILL_MS + FLASH_MS, duration: REFILL_MS };
  return null;
}

export type InkTone = 'vermilion' | 'seal' | 'chalk';
export type InkDrop = { dx: number; dy: number; size: number; tone: InkTone };

const JITTER = [0, 0.31, -0.22, 0.17, -0.35, 0.08, 0.26, -0.12];
const REACH = [1, 0.62, 0.84, 0.71, 0.93];
const SIZES = [9, 5, 7, 3, 6, 4];
const TONES: readonly InkTone[] = ['vermilion', 'chalk', 'seal'];

/** The ink splash's drops (spec decision 3, plan decision 3): a fixed table, never random, so every run is the same. */
export function inkDrops(count: number, radius: number): InkDrop[] {
  return Array.from({ length: count }, (_, i) => {
    const angle = ((i + JITTER[i % JITTER.length]!) / count) * 2 * Math.PI;
    const reach = radius * REACH[i % REACH.length]!;
    return { dx: Math.cos(angle) * reach, dy: Math.sin(angle) * reach, size: SIZES[i % SIZES.length]!, tone: TONES[i % TONES.length]! };
  });
}
```

```ts
// M10a: the hooks behind the motion pieces. `useReduce` reads the phone's "Remove animations" (Reanimated reads it once,
// at launch) unless a test or the motion bench overrides it.
import { useEffect, useRef, useState } from 'react';
import { cancelAnimation, useAnimatedReaction, useReducedMotion, useSharedValue, withDelay, withTiming } from 'react-native-reanimated';
import { scheduleOnRN } from 'react-native-worklets';
import { timing } from './motion.ts';
import type { CountPlan } from './motion.ts';

export function useReduce(override?: boolean): boolean {
  const phone = useReducedMotion();
  return override ?? phone;
}

/** How many times `value` has risen since the first value: 0 until it does, so opening a screen never animates. */
export function useGrowth(value: number | null): number {
  const last = useRef(value);
  const [grown, setGrown] = useState(0);
  useEffect(() => {
    if (value !== null && last.current !== null && value > last.current) setGrown((n) => n + 1);
    last.current = value;
  }, [value]);
  return grown;
}

/**
 * A number counting to `to` (plan decision 5): a shared value runs the count on the UI thread, and each whole number it
 * passes is sent back to React. Without a plan, or with reduced motion, it is `to` at once. Reanimated's Jest mock never
 * calls the reaction, so in a test a counting number stays at its start.
 */
export function useCountUp(plan: CountPlan | null, to: number, reduceMotion?: boolean): number {
  const reduce = useReduce(reduceMotion);
  const start = plan !== null && !reduce ? plan.from : to;
  const [shown, setShown] = useState(start);
  const n = useSharedValue(start);
  useAnimatedReaction(
    () => Math.round(n.value),
    (now, before) => {
      if (now !== before) scheduleOnRN(setShown, now);
    },
  );
  const from = plan?.from ?? null;
  const delay = plan?.delay ?? 0;
  const duration = plan?.duration ?? 0;
  useEffect(() => {
    if (from === null || reduce) return;
    cancelAnimation(n);
    n.value = from;
    n.value = withDelay(delay, withTiming(to, timing(duration)));
  }, [from, delay, duration, to, reduce, n]);
  // Not counting, the end comes straight from the props: no state update, so no extra render.
  return from === null || reduce ? to : shown;
}
```

```tsx
// Speed lines (visual spec §2): thin radial strokes behind a big moment, drawn once for the laid-out size. M10a: `burst`
// (the reveal, a level-up, quest cleared; visual spec §3) scales the drawing out from 0.6 as it fades in, once, as one

import Animated, { useAnimatedStyle, useSharedValue, withTiming } from 'react-native-reanimated';
import Svg, { Line } from 'react-native-svg';

import { useReduce } from './useMotion.ts';
import { useSize } from './useSize.ts';

const RAYS = 36;

export function SpeedLines({ opacity = 0.12, burst = false, reduceMotion }: { opacity?: number; burst?: boolean; reduceMotion?: boolean }) {
  const [size, onLayout] = useSize();
  const reduce = useReduce(reduceMotion);
  const progress = useSharedValue(burst ? 0 : 1);
  useEffect(() => {
    if (burst) progress.value = withTiming(1, timing(reduce ? FADE_MS : BURST_MS));
  }, [burst, reduce, progress]);
  const bursting = useAnimatedStyle(() => ({ opacity: progress.value, transform: [{ scale: BURST_FROM + (1 - BURST_FROM) * progress.value }] }));
  const fading = useAnimatedStyle(() => ({ opacity: progress.value }));
  return (
    <Animated.View
      testID="speed-lines" pointerEvents="none" importantForAccessibility="no-hide-descendants" accessibilityElementsHidden onLayout={onLayout}
      style={[StyleSheet.absoluteFill, burst ? (reduce ? fading : bursting) : null]}
    >
      {size !== null && (
        <Svg width={size.width} height={size.height}>
          {Array.from({ length: RAYS }, (_, i) => {
            const angle = (i / RAYS) * 2 * Math.PI;
            const cx = size.width / 2;
            const cy = size.height / 2;
            const outer = Math.hypot(cx, cy);
            const inner = outer * (i % 2 === 0 ? 0.35 : 0.5);
            return (
              <Line
                key={i}
                x1={cx + Math.cos(angle) * inner} y1={cy + Math.sin(angle) * inner}
                x2={cx + Math.cos(angle) * outer} y2={cy + Math.sin(angle) * outer}

              />
            );
```

```tsx
// The ink splash (M10a; the video's confetti in the ink-panel look): drops fly out from behind the centre of what it
// wraps and fade, once. Positions come from a fixed table (`inkDrops`). Decoration only: no touches, no screen reader.
// With reduced motion it draws nothing.
import type { ReactNode } from 'react';
import { useEffect } from 'react';
import { StyleSheet, View } from 'react-native';
import type { StyleProp, ViewStyle } from 'react-native';
import Animated, { Easing, useAnimatedStyle, useSharedValue, withDelay, withTiming } from 'react-native-reanimated';
import type { SharedValue } from 'react-native-reanimated';
import { colors } from '../theme/tokens.ts';
import { INK_MS, inkDrops, timing } from './motion.ts';
import type { InkDrop } from './motion.ts';
import { useReduce } from './useMotion.ts';

function Drop({ drop, progress }: { drop: InkDrop; progress: SharedValue<number> }) {
  const flying = useAnimatedStyle(() => {
    const p = progress.value;
    return {
      opacity: p === 0 ? 0 : p < 0.15 ? p / 0.15 : 1 - (p - 0.15) / 0.85,
      transform: [{ translateX: drop.dx * p }, { translateY: drop.dy * p }, { scale: 1 - 0.4 * p }],
    };
  });
  return (
    <Animated.View
      testID="ink-drop"
      style={[{ position: 'absolute', width: drop.size, height: drop.size, borderRadius: drop.size / 2, backgroundColor: colors[drop.tone] }, flying]}
    />
  );
}

export function InkBurst({ children, count = 12, radius = 80, delay = 0, style, reduceMotion }: {
  children: ReactNode;
  count?: number;
  radius?: number;
  delay?: number;
  style?: StyleProp<ViewStyle>;
  reduceMotion?: boolean;
}) {
  const reduce = useReduce(reduceMotion);
  const progress = useSharedValue(0);
  useEffect(() => {
    if (!reduce) progress.value = withDelay(delay, withTiming(1, timing(INK_MS, Easing.out(Easing.quad))));
  }, [reduce, delay, progress]);
  return (
    <View style={style}>
      {!reduce && (
        <View
          testID="ink-burst" pointerEvents="none" accessibilityElementsHidden importantForAccessibility="no-hide-descendants"
          style={[StyleSheet.absoluteFill, { alignItems: 'center', justifyContent: 'center' }]}
        >
          {inkDrops(count, radius).map((drop, i) => <Drop key={i} drop={drop} progress={progress} />)}
        </View>
      )}
      {children}
    </View>
  );
}
```

```tsx
// The XP bar (D1 Today, D2 Quest cleared): a 14 px bar with a 2 px border (chalk on the night, ink on paper) and a
// vermilion fill. M10a: given its `level`, the bar moves (spec decisions 3, 5, 7). It fills from `from` when it opens
// (Quest cleared), then from what it last showed whenever the value changes (Today after a sync). Across a level it
// fills to the end, flashes chalk and fills again from empty. A drop shows at once, and so does everything with reduced
// motion. Its accessibility value is always the new one. Without a level it never moves (stat bars, timers, the trial).
import { useEffect, useRef } from 'react';
import { StyleSheet, View } from 'react-native';
import Animated, { cancelAnimation, useAnimatedStyle, useSharedValue, withDelay, withSequence, withTiming } from 'react-native-reanimated';
import { colors } from '../theme/tokens.ts';
import { FILL_MS, FLASH_MS, REFILL_MS, WRAP_FILL_MS, fillFraction, fillSegments, timing } from './motion.ts';
import type { BarPoint } from './motion.ts';
import { useReduce } from './useMotion.ts';

export { fillFraction } from './motion.ts';

type BarProps = { value: number; max: number; label: string; on?: 'night' | 'paper' };

export type XpBarProps = BarProps & {
  /** The level this XP is in; given, the bar moves (M10a). */
  level?: number;
  /** What it showed before it opened: Quest cleared's "before". */
  from?: BarPoint | null;
  /** Milliseconds before the first fill. */
  delay?: number;
  /** Overrides the phone's setting (tests, the motion bench). */
  reduceMotion?: boolean;
};

const frame = (on: 'night' | 'paper') => ({
  height: 14, borderWidth: 2, borderColor: on === 'paper' ? colors.ink : colors.chalk, backgroundColor: on === 'paper' ? colors.paper : colors.night,
});

export function XpBar({ level, from = null, delay = 0, reduceMotion, ...bar }: XpBarProps) {
  return level === undefined
    ? <StillBar {...bar} />
    : <MovingBar {...bar} level={level} from={from} delay={delay} reduceMotion={reduceMotion} />;
}

function StillBar({ value, max, label, on = 'night' }: BarProps) {
  return (
    <View accessible accessibilityRole="progressbar" accessibilityLabel={label} accessibilityValue={{ min: 0, max, now: value }} style={frame(on)}>
      <View testID="xp-fill" style={{ width: `${fillFraction(value, max) * 100}%`, height: '100%', backgroundColor: colors.vermilion }} />
    </View>
  );
}

function MovingBar({ value, max, label, on = 'night', level, from, delay, reduceMotion }: BarProps & {
  level: number;
  from: BarPoint | null;
  delay: number;
  reduceMotion?: boolean;
}) {
  const reduce = useReduce(reduceMotion);
  const start = reduce || from === null ? { level, value, max } : from;
  const last = useRef<BarPoint>(start);
  const first = useRef(true);
  const fill = useSharedValue(fillFraction(start.value, start.max));
  const flash = useSharedValue(0);
  useEffect(() => {
    const was = last.current;
    last.current = { level, value, max };
    const wait = first.current ? delay : 0;
    first.current = false;
    cancelAnimation(fill);
    cancelAnimation(flash);
    flash.value = 0;
    const steps = reduce ? [] : fillSegments(was, { level, value, max });
    if (steps.length === 0) {
      fill.value = fillFraction(value, max);
      return;
    }
    fill.value = steps[0]!.from;
    if (steps.length === 1) {
      fill.value = withDelay(wait, withTiming(steps[0]!.to, timing(FILL_MS)));
      return;
    }
    fill.value = withDelay(wait, withSequence(
      withTiming(1, timing(WRAP_FILL_MS)),
      withTiming(1, timing(FLASH_MS)), // holds at full while it flashes
      withTiming(0, timing(0)),
      withTiming(steps[1]!.to, timing(REFILL_MS)),
    ));
    flash.value = withDelay(wait + WRAP_FILL_MS, withSequence(withTiming(1, timing(FLASH_MS / 2)), withTiming(0, timing(FLASH_MS / 2))));
  }, [level, value, max, reduce, delay, fill, flash]);
  const width = useAnimatedStyle(() => ({ width: `${fill.value * 100}%` }));
  const flashing = useAnimatedStyle(() => ({ opacity: flash.value }));
  return (
    <View accessible accessibilityRole="progressbar" accessibilityLabel={label} accessibilityValue={{ min: 0, max, now: value }} style={frame(on)}>
      <Animated.View testID="xp-fill" style={[{ height: '100%', backgroundColor: colors.vermilion }, width]} />
      {!reduce && <Animated.View testID="xp-flash" pointerEvents="none" style={[StyleSheet.absoluteFill, { backgroundColor: colors.chalk }, flashing]} />}
    </View>
  );
}
```

```tsx
function Counted({ reduce }: { reduce: boolean }) {
  const n = useCountUp(countPlan({ level: 6, value: 40, max: 130 }, { level: 6, value: 87, max: 130 }, 0), 87, reduce);
  return <Caption>{`${n} / 130 XP`}</Caption>;
}

export default function MotionBench() {
  const insets = useSafeAreaInsets();
  const store = useGameStore();
  const [replay, setReplay] = useState(0);
  const [reduce, setReduce] = useState(false);
  const [cleared, setCleared] = useState<ClearedNumbers | null>(null);
  const again = () => setReplay((n) => n + 1);

  if (cleared !== null) {
    return (
      <View key={replay} style={{ flex: 1, backgroundColor: colors.night }}>
        <Cleared heading="CORE QUEST · KNEE PUSH-UPS" line="3 sets of 8" numbers={cleared} rating={null} dayOpen waiting={false}
          onRate={() => {}} onUndo={again} onContinue={() => setCleared(null)} canStepDown={false} onStepDown={() => {}} onPain={null} />
      </View>
    );
  }
  return (
    <ScreenScroll contentContainerStyle={{ paddingTop: insets.top + 12, paddingBottom: insets.bottom + 32, paddingHorizontal: space.gutter, gap: 20 }}>
      <Button label="Back" variant="secondary" onPress={() => router.back()} />
      <Title>Motion</Title>
      <Small>Motion bench: replay each piece and moment. In Quest cleared, Undo replays it and Continue comes back here.</Small>
      <Button label="Replay" onPress={again} />
      <Button
        label={reduce ? 'Reduced motion: on (the pieces)' : 'Reduced motion: off'}
        variant="secondary"
        onPress={() => {
          setReduce(!reduce);
          again();
        }}
      />

      <SectionTitle title="Pieces" />
      <View key={replay} style={{ gap: 28 }}>
        <SlamIn reduceMotion={reduce}><NarrationBox>SlamIn: 180 ms.</NarrationBox></SlamIn>
        <View style={{ flexDirection: 'row', justifyContent: 'space-around', alignItems: 'center', minHeight: 130 }}>
          <Thud reduceMotion={reduce}><XpStamp xp={20} /></Thud>
          <InkBurst reduceMotion={reduce}>
            <Thud reduceMotion={reduce}><XpStamp xp={30} size={86} rotate={12} /></Thud>
          </InkBurst>
          <Thud reduceMotion={reduce}><MarkStamp text="Sworn" /></Thud>
        </View>
        <View style={{ height: 160, alignItems: 'center', justifyContent: 'center', borderWidth: 2, borderColor: colors.line }}>
          <SpeedLines burst opacity={0.18} reduceMotion={reduce} />
          <Heading>Speed lines</Heading>
        </View>
        <View style={{ gap: 8 }}>
          <XpBar value={87} max={130} level={6} from={{ level: 6, value: 40, max: 130 }} reduceMotion={reduce} label="Fill" />
          <Counted reduce={reduce} />
          <XpBar value={30} max={150} level={7} from={{ level: 6, value: 117, max: 130 }} reduceMotion={reduce} label="Wrap" />
        </View>
        <FadeIn rise reduceMotion={reduce}><Body>FadeIn, rising 12 px.</Body></FadeIn>
      </View>

      <SectionTitle title="Moments" />
      <Button label="Quest cleared" variant="secondary" onPress={() => setCleared(SAMPLE)} />
      <Button label="Quest cleared, with a level-up" variant="secondary" onPress={() => setCleared(LEVELLED)} />
      <Button label="Level up to 5" variant="secondary" onPress={() => store.setState({ celebrations: [{ kind: 'level', level: 5, from: 4 }] })} />
      <Button label="An achievement" variant="secondary" onPress={() => store.setState({ celebrations: [{ kind: 'achievement', id: ACHIEVEMENTS[0]!.id }] })} />
    </ScreenScroll>
  );
}
```
